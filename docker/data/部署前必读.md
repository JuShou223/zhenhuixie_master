## 真会写 部署说明

### 1. 打包后端 jar

```bash
cd RuoYi-Vue
mvn clean package -Dmaven.test.skip=true
cp ./ruoyi-admin/target/ruoyi-admin.jar /var/data/java/ruoyi-admin.jar
```

### 2. 打包前端 H5

```bash
# 在 HBuilderX 中选择「发行 → 网站-H5」，或命令行：
cd uni-app-starter
npm install
npm run build:h5
cp -rf ./dist/build/h5/* /var/data/nginx/h5/
```

### 3. 放入初始化 SQL

三个文件按顺序命名后放入 `initdb/`，容器首次启动会自动按文件名顺序执行：

```bash
cp RuoYi-Vue/sql/ry_20260321.sql  /var/data/mysql/initdb/01_ry.sql
cp RuoYi-Vue/sql/quartz.sql       /var/data/mysql/initdb/02_quartz.sql
cp RuoYi-Vue/sql/zhw_init.sql     /var/data/mysql/initdb/03_zhw.sql
```

> 注意：`initdb/` 目录下的 SQL 只在 MySQL 容器**首次创建**时自动执行。
> 若数据库已存在，需手动按上述顺序导入。

### 4. 启动项目

```bash
cd /var/data
chmod 777 -R /var/data
chmod 644 /var/data/mysql/mysql.cnf
docker-compose up -d
```

> 注意：必须在 `chmod 777` 之后单独执行 `chmod 644 mysql.cnf`，否则 MySQL 会因安全策略忽略该配置文件，导致中文乱码。

### 5. 默认访问

| 地址 | 说明 |
|------|------|
| `http://服务器IP` | 前端 H5 |
| `http://服务器IP/prod-api` | 后端接口 |
